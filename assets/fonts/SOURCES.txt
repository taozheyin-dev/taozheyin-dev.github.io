The official variable fonts are subset with fontTools, preserving the weight axis.
The subset includes the characters in all generated root HTML, CSS and portfolio.js.
The build checks Chinese and full-width punctuation coverage against each font cmap.
No glyph outlines have been redesigned. Hinting is removed for the web subset.
Run python scripts/build.py followed by python scripts/fonts.py after changing copy.
Official source fonts downloaded on 2026-10-17; subsets regenerated by scripts/fonts.py.
Fonts are served locally at runtime.
