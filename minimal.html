04 / Insights

🎯 工具选择的“解耦与卡位”原则

不迷信单一全能 Agent。架构设计由深层推理的 Claude 挂帅，快速打样选 Codex，海量长文本交由 Kimi，日常多模型编排以 ZCode 为调度中枢。

🔧 自建 API 网关的“主权价值”

网关不仅是格式转换器，更是应对大模型供应链风险的防御性基础设施：打破协议孤岛、抹平首字延迟差异、多 Key 轮转对冲限流与单点故障。

⚙️ 大规模配置的“代码化治理”

管理 34 渠道与 81 模型绝不靠手工点选。所有路由规则与思考档位纳入 Git 版本控制，脚本自动化回归校验，关键状态定期落地 SQLite 镜像。

🐛 诊断调试的“日志驱动与变量隔离”

排障拒绝凭感觉猜测。善用底层 logs.sqlite3 审计抓包定位真实载荷；凡失败两次立即停下手头代码，回归第一性原理并逐一隔离环境变量。

🤝 开源协作的“敬畏心与交付标准”

提交 PR 必须由干净代码、单元测试与清晰文档共同组成。尊重维护者评审意见，在 Issue 和 Code Review 中坚持用实测日志与数据说话。

📈 持续优化的“量化指标意识”

持续监控 TTFB 与流式 Chunk 延迟，关注边缘计算成本（CF D1 配额 0.09%），定期清理技术债务并紧跟 upstream 演进。
